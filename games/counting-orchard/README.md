# Counting Orchard

A 3D counting game built with [Three.js](https://threejs.org/). Fruit appears in a basket in a sunny orchard — tap each one to count it out loud (1… 2… 3…), then pick the number that matches. Teaches one-to-one counting, number recognition, and subitizing (seeing "how many" at a glance).

Four levels grow from 1–5 up to 1–20, with a streak meter and a level picker. Apples, oranges, plums, and limes keep it fresh.
