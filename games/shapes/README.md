# Shapes

A 3D shape explorer built with [Three.js](https://threejs.org/). Flip through flat shapes (circle, square, star, heart…) and solids (cube, sphere, cone, pyramid, donut…) on a pedestal — each one spins, and tapping it says its name out loud. Builds geometry vocabulary and shape recognition.

**Play:** [mama.dev/games/shapes](https://mama.dev/games/shapes/)

Part of [mama.dev](https://mama.dev) — small things built for a small person.
