# Carrot Ten-Frame

A 3D ten-frame game built with [Three.js](https://threejs.org/). Two bunnies wait by a carrot patch while you fill a wooden ten-frame tray with carrots. Builds counting, number recognition, and — the big one — **number bonds to 10** (base-10 intuition).

Tap a cell to plant a carrot; tap it again to pull it out. Four levels grow with the child:

1. **Count to 5** — "Put 5 carrots in!" Fill the frame to match the number.
2. **Count to 10** — same, up to ten.
3. **Make Ten** — some cells start full: "7 in — how many more to make 10?" Fill the rest.
4. **Ten Master** — make ten from smaller starts (the trickier bonds).

Streak meter, level picker, the count spoken aloud, and happy hopping bunnies + confetti on success.
