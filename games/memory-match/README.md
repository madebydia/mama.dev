# Memory Match

A 3D pairs game built with [Three.js](https://threejs.org/). Cards lie face-down on a checkered picnic blanket — tap to flip them over and find the matching pairs. Builds working memory and turn-taking patience.

Boards grow from 2 pairs (2×2) up to 8 pairs (4×4), advancing when a board is cleared. Score counts pairs found.
