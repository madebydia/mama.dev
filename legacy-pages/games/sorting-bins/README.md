# Sorting Bins

A 3D classification game built with [Three.js](https://threejs.org/). An item pops onto the backyard stump — tap the labeled crate it belongs in and it arcs inside with a plop. Sorting is foundational logic: by color (2 then 3 bins), by shape, then big vs small.

Streak meter, level picker, spoken prompts.

**Play:** [mama.dev/games/sorting-bins](https://mama.dev/games/sorting-bins/)

Part of [mama.dev](https://mama.dev) — small things built for a small person.
