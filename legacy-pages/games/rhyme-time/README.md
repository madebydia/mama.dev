# Rhyme Time

A 3D rhyming game built with [Three.js](https://threejs.org/). On a twilight lane, houses show picture signs — hear a word ("Cat! Which one rhymes with cat?") and tap the rhyming house; its window glows warm. Builds phonological awareness, the other pillar of early reading.

Levels grow from 2 to 4 choices across ~14 rhyme families. Streak meter, spoken prompts with a repeat button.

**Play:** [mama.dev/games/rhyme-time](https://mama.dev/games/rhyme-time/)
