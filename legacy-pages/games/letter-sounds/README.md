# Sound Safari

A 3D letter-sounds game built with [Three.js](https://threejs.org/). Big letter blocks sit on the savanna — hear a letter name or a first sound ("mmm… moon starts with mmm!") and tap the right block. The sound→symbol link that turns a speller into a reader.

Levels: letter names → first sounds → tricky look-alike letters (b/d/p…). Streak meter, level picker, spoken prompts with a repeat button.

**Play:** [mama.dev/games/letter-sounds](https://mama.dev/games/letter-sounds/)

Part of [mama.dev](https://mama.dev) — small things built for a small person.
