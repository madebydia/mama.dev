# Pattern Parade

A 3D pattern game built with [Three.js](https://threejs.org/). A parade of colored shapes marches past the circus tents with one empty pedestal at the end — tap which shape comes next. Early algebra: AB → AAB/ABB → ABC → mixed (including same-shape, different-color patterns).

Streak meter, level picker, and the winning shape flies into place with a wave bounce.
