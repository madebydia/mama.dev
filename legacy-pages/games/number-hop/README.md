# Number Hop

A 3D number-line game built with [Three.js](https://threejs.org/). A frog sits on a numbered lily pad — tap the number that comes after, before, between, or two more, and the frog hops there. Builds sequencing and the mental number line (1–10).

Levels: one more → one less → in between → two more. Streak meter, level picker, spoken prompts.

**Play:** [mama.dev/games/number-hop](https://mama.dev/games/number-hop/)
