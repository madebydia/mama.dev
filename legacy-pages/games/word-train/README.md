# Word Train

A 3D phonics game for early readers, built with [three.js](https://threejs.org/). Build words and watch the train chug away.

Three levels that grow with the reader:

1. **Fill it** — complete a word with the missing letter (`c_t`, `_ot`, `ba_`). Choices are limited and always include a correct answer.
2. **Spell it** — spell the word for the picture on the signboard (🐱 → `cat`). Tap 🔊 to hear it.
3. **Make it** — free play: build any real three-letter word.

Five wins advances to the next level. Teaches blending, letter recognition, and CVC words.
