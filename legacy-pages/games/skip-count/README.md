# Skip-Count Stones

A 3D skip-counting game built with [Three.js](https://threejs.org/). A duck crosses the river on stepping stones that count by 10s, 5s, or 2s — each correct answer reveals the next stone and the duck hops on, all the way across. Multiplication's warm-up act.

Levels: by tens → by fives → by twos → mixed. Streak meter, level picker, spoken counting.
